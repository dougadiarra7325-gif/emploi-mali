# Emploi Mali — Portail d'offres d'emploi au Mali

**Projet n°4 « Offres d'emploi au Mali »** de l'atelier **IAM Code to Career** (Université IAM, Bamako — DataInsights), réalisé par **Douga dit Ibrahim Diarra**, étudiant en Licence 2 informatique.

## Version hébergée ici (GitHub Pages)
Version de **démonstration publique** : catalogue d'offres avec recherche par mot-clé et filtres (secteur, ville, type de contrat), fiche détaillée de chaque offre, et démonstration des espaces **candidat** (profil, candidatures, alertes) et **recruteur** (publication d'offres) — les données de démonstration restent sur l'appareil du visiteur.

Les 8 offres affichées sont des exemples d'entreprises fictives, marqués « Démo ».

## Version complète
La version complète du portail fonctionne avec de vrais comptes candidat/recruteur et une base de données côté serveur (publication d'offres visible par tous, candidatures conservées, statuts Envoyée/Vue, alertes) — elle tourne séparément et sert à la démonstration en classe.
